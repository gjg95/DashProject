# DashProject

Dash dashboard for visualizing industrial plant equipment data (see README.md).

## Workflow

- Use Plan Mode before new features, significant design tradeoffs, and bugs
  that survive the first attempted fix.
- Delegate focused supporting work to the project subagents:
  - `search` — map the repo / find definitions and call sites.
  - `tests` — run pytest and report failures (it does not fix them).
  - `docs` — look up library API documentation.
